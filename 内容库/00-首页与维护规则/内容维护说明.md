# 内容维护说明

本文件仅保留内容资产维护约定。任务路由由项目根目录 `AGENTS.md` 负责；具体执行分别由 `idea-intake`、`topic-planning`、`video-copywriting`、`publish-archive` 四个 Skill 负责。历史扫描规则见 `.codex/skills/topic-planning/references/history-vault-rules.md`。

- 一条已发布视频只建立一篇历史笔记，不因多个分类复制。
- 历史内容按实际发布日期保存到 `01-历史内容/YYYY/YYYY-MM/`；分类依赖 Frontmatter 和 wikilink。
- `business_line` 表示服务板块，`theme` 表示具体主题；固定值以 [[固定选项库]] 为准。
- 内容资产按“原始线索 → 灵感库 → 待发布选题或业务选题池 → 用户确认 → 文案 → 实际发布 → 明确归档 → 历史内容与灵感回流”流转。
- [[选题灵感收集]] 只作独立录入索引；灵感、竞品数据或热点仅能作为参考，不能替代历史避重、服务关联和事实核验。
- [[待发布选题]] 与各业务选题池只保存已补全场景和服务关联的成熟候选；候选需使用统一候选卡字段。
- 只有“实际发布”且“明确归档/写入”同时满足，才按 [[历史内容归档规范]] 写入历史库；用户仅说明已发布时，先准备归档预览；归档后将可靠的延展问题、评论或咨询反馈另建灵感笔记回流。
- 历史笔记只用于去重和覆盖分析，不能证明当前政策仍有效；涉及公司法、税法、登记、申报、税率、期限或处罚时必须核验官方来源。
