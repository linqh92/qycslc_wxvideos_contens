# 客户痛点覆盖情况

| 痛点 | 当前覆盖 | 优先级 | 说明 |
| --- | ---: | --- | --- |
| 创始合伙的出资与经营贡献难对齐 | 1 | 高 | 已覆盖一方出资、一方经营的贡献拆分；需继续补充创业前的比例与协议设计。 |
| 控制权与表决权安排 | 3 | 高 | 已覆盖比例接近时的决策场景，以及创业前持股不高时的关键事项安排；后续可补充预留股权的控制权边界。 |
| 引入合伙人或核心人才时的股权安排 | 2 | 高 | 已覆盖不同合伙人类型的区分，以及新合伙人进入前的条件与阶段目标梳理。 |
| 合伙人退出与资料交接 | 1 | 高 | 已覆盖退出协商前的资料与交接边界梳理。 |
| 融资与股权稀释 | 1 | 高 | 已覆盖增资融资时的稀释与控制权衔接；后续可补充预留股权与融资测算。 |
| 股权转让税务与资料 | 2 | 中 | 已覆盖账务资料和成本资料归集；涉及规则时仍需官方核验。 |
| 员工持股 | 2 | 中 | 已覆盖退出与回购安排，以及创业期预留未来人员股权的进入与调整边界；后续补充授予与归属条件。 |
| 公司章程与股东协议 | 1 | 高 | 已覆盖创业前出资、分工、决策与后续调整的整体对齐；后续可补充协议与章程的一致性核对。 |
| 常规财税合规 | 0 | 低 | 仅围绕股权设计或调整场景展开。 |

> 家族企业传承、成熟企业重组和关联架构属于历史定位方向，不计入当前新增选题的覆盖缺口。
