# 企业财税-老陈｜微信视频号

本仓库用于管理“企业财税-老陈”微信视频号的内容生产与获客闭环，重点服务已有一定经营规模、正在处理股权与税务决策的企业。

## 账号定位

- 核心方向：企业股权设计、股权架构、家族企业治理、合伙人纠纷后的股权调整，以及与股权交易相关的财税合规与税务筹划。
- 目标客户：成熟企业的创始人、实际控制人、股东、财务负责人及家族企业接班人；不限定具体行业。
- 内容目标：用真实经营场景帮助老板先识别控制权、退出机制、交易税负和资料链条问题，自然承接股权与财税合规咨询。

## 唯一工作流入口

使用 `.codex/skills/daily-video-account-planning/SKILL.md` 执行每日内容工作流：

`扫描知识库 → 规划选题 → 用户确认 → 生成文案 → 用户确认发布 → 用户确认归档 → 更新索引与复盘`

内容库位于 `内容库/`。历史内容是去重和覆盖判断的唯一来源；政策、税率、期限和登记流程须另行核验当前官方来源。
