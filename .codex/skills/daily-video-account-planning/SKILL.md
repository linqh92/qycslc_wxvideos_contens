# 企业财税-老陈｜视频号内容工作流

本技能只负责按动作路由，服务“企业财税-老陈”既定定位：面向成熟企业的股权架构、公司治理、股权交易与相关财税合规服务。不得因参考流程扩大为泛创业、泛代理记账或追逐热点的账号。

| 用户动作 | 必读模块 | 结果 |
| --- | --- | --- |
| 独立录入灵感：提供图片或文字 | [灵感录入](references/idea-intake-workflow.md) | 仅建立一篇灵感笔记后结束。 |
| 要求选题、分析方向或查看内容缺口 | [知识库读取说明](references/obsidian-history-vault.md) + [选题决策](references/topic-selection-workflow.md) | 输出 5 个可选方案。 |
| 确认选题后要求写/修改文案 | [文案生成](references/original-copywriting-guide.md) | 生成并检查文案。 |
| 说明内容已发布，或要求归档 | [发布与归档](references/publish-and-archive-workflow.md) + `内容库/00-首页与维护规则/历史内容归档规范.md` | 准备归档预览，或执行归档与回流。 |

## 全局边界

- 灵感录入是独立流程：只建立单条灵感笔记，不自动触发选题、候选入池、文案生成、官方核验、历史扫描或归档。图片仅提取可读文字，不保存、嵌入或链接图片。
- 不调用热点 API，不把平台热度、排名或跨平台出现次数作为选题依据；不按早、中、晚安排内容。每次选题均由用户需求触发，统一提供 5 个互不重复方案。
- 历史内容库是已发布内容、去重和覆盖判断的唯一事实来源；灵感库与选题池是候选资产，不替代历史库。
- 用户只确认选题或文案时，不写入历史内容库。只有“实际发布”与“明确归档/写入”同时满足时，才能归档。
- 政策、税率、期限、处罚、办理流程等确定性结论必须核验当前官方来源。
- 不编造政策、案例、数据或处罚结果；不夸大风险、承诺结果或传播规避监管方法。
